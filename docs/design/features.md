# 機能一覧

仕様書（`docs/spec.md`）と、モックアップ（`mockup/`、`design-guide.md` を含む）を突き合わせて整理したもの。
各項目の根拠は「仕様書 n-n」または `mockup/ファイル名` の形で示す。

## 1. 機能一覧

| F-02 | ログイン（メールアドレス・パスワード） | 仕様書 3-1 / `mockup/login.html` |

## 2. 今回作らないもの（スコープ外）

仕様書 4. の表をそのまま転記。

| 作らないもの | 理由 |
| :-- | :-- |
| 新着メッセージの自動表示（画面を開いたままで届く） | 今回は画面を開き直して確認できれば十分 |
| 通知（メール・スマートフォンへの通知） | まずは社内で使い始められる形を優先したい |
| 1対1のダイレクトメッセージ | チャンネルでの会話に絞りたい |
| ファイル・画像の添付 | 文章のやり取りに絞りたい |
| メッセージへのリアクション（絵文字を付ける） | 会話ができることを優先したい |
| 未読・既読の管理 | 同上 |
| 管理者による全体管理（利用者の停止、他人のチャンネルの管理） | 運用が固まってから考えたい |

このほか、モックアップとの突き合わせで分かった「作らない（今回は要らない）」と判断できる点：

| 作らないもの | 根拠 |
| :-- | :-- |
| スマートフォン表示への対応 | 仕様書 5-2「使うのは PCのブラウザです」/ `design-guide.md`「画面の最小幅は1280px。レスポンシブ対応はしません」 |
| 返信への返信（スレッドの入れ子） | `mockup/thread.html` のスレッドパネルは1階層のみで、返信をさらに返信する導線がない（※この解釈については questions.md Q-09 で確認） |
