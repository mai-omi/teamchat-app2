# 受け入れ条件・テスト観点

`features.md`・`questions.md`・`screens.md`・`data.md`・`permissions-api.md`・`behavior.md` と、`spec.md`・`mockup/` を根拠に作成。
根拠の書き方は他のファイルと同じ。

実装単位は7つ、番号は次の並びの順に固定する。

| 単位番号 | 実装単位 | 対応するF-ID |
| :-- | :-- | :-- |
| 1 | 認証 | F-01〜F-03 |
| 2 | チャンネル | F-04〜F-11 |
| 3 | メンバー管理 | F-12〜F-14 |
| 4 | メッセージ | F-15〜F-19 |
| 5 | スレッド | F-20〜F-22 |
| 6 | 検索 | F-23〜F-26 |
| 7 | 公開API | F-27〜F-29 |

F-30（文字数上限）は各単位の受け入れ条件・テスト観点の中に織り込み、単位としては立てない（上限は単位をまたいで出てくる横断的な制約のため）。F-31（初期データ投入）も単位としては立てず、1.（認証）の受け入れ条件で、初期データのアカウント（`spec.md 5-4`）を使うことで間接的に確かめる。

---

## 1. 受け入れ条件

1つの実装単位につき2〜4行。「〜すると、〜になる」の形で、ブラウザでの操作だけで合否が決まるように書く。網羅はしない（2.のテスト観点に譙る）。

### 1. 認証（AC-1）

| ID | 受け入れ条件 |
| :-- | :-- |
| AC-1-1 | 未登録のメールアドレスで表示名・メールアドレス・パスワード・パスワード（確認用）を入力して登録すると、自動的にログイン状態になり、チャンネル一覧画面が表示される。 |
| AC-1-2 | 初期データのメールアドレス（`sato@example.com`）と正しいパスワードでログインすると、チャンネル一覧画面が表示される。 |
| AC-1-3 | パスワードを間違えてログインすると、ログイン画面に「メールアドレスまたはパスワードが正しくありません」と表示され、ログインできない。 |
| AC-1-4 | ログイン中に「ログアウト」を押すと、ログイン画面に戻る。そのあとログインが必要な画面のURLを直接開くと、ログイン画面に送り直される。 |

### 2. チャンネル（AC-2）

| ID | 受け入れ条件 |
| :-- | :-- |
| AC-2-1 | チャンネル名・説明を入力し「公開」を選んで作成すると、作成したそのチャンネルの画面が開き、チャンネル一覧にもそのチャンネルが表示される。 |
| AC-2-2 | 「プライベート」を選んで作成すると、作成した自分はそのチャンネルを開けるが、メンバーに追加していない別の利用者でログインすると、チャンネル一覧にそのチャンネルの名前が表示されない。 |
| AC-2-3 | 作成者としてチャンネル名・説明を変更して保存すると、チャンネルの画面にその新しい名前・説明が表示される。 |
| AC-2-4 | 作成者としてチャンネルの削除画面で、確認欄にチャンネル名を正しく入力してから削除すると、チャンネル一覧からそのチャンネルが消える。 |

### 3. メンバー管理（AC-3）

| ID | 受け入れ条件 |
| :-- | :-- |
| AC-3-1 | プライベートチャンネルの作成者が、メンバー管理画面で表示名（またはメールアドレス）を入力して追加すると、その人がメンバー一覧に表示され、その人でログインするとそのチャンネルを開けるようになる。 |
| AC-3-2 | 作成者がメンバーの「外す」を押すと、その人はメンバー一覧から消え、その人でログインするとそのチャンネルを開けなくなる。 |
| AC-3-3 | 作成者自身の行の「外す」ボタンは押せない状態になっている。 |
| AC-3-4 | 公開チャンネルを開くと、メンバー管理の画面やボタンがどこにも表示されない。 |

### 4. メッセージ（AC-4）

| ID | 受け入れ条件 |
| :-- | :-- |
| AC-4-1 | チャンネルの投稿欄に本文を入力して送信すると、メッセージ一覧の末尾に、自分の名前・投稿日時とともにその本文が表示される。 |
| AC-4-2 | 自分のメッセージを編集して保存すると、本文が新しい内容に変わり、末尾に「編集済み」と表示される。 |
| AC-4-3 | 自分のメッセージを削除すると、その場所の本文が「このメッセージは削除されました」に変わるが、投稿者名と日時はそのまま表示される。 |
| AC-4-4 | 他の人が書いたメッセージにマウスを乗せても、編集・削除のボタンは表示されない。 |

### 5. スレッド（AC-5）

| ID | 受け入れ条件 |
| :-- | :-- |
| AC-5-1 | メッセージの「返信」から本文を送信すると、右側にスレッドパネルが開き、元のメッセージの下にその返信が表示される。 |
| AC-5-2 | 返信を送ったあとチャンネルのメッセージ一覧を見ると、返信はそこには流れず、元のメッセージの下に「返信n件」のリンクだけが表示される。 |
| AC-5-3 | 返信が付いた元のメッセージを削除すると、本文は「このメッセージは削除されました」に変わるが、「返信n件」のリンクは表示され続け、開くとこれまでの返信を読める。 |
| AC-5-4 | 削除済みの元のメッセージに対して、新しく返信を送信できる。 |

### 6. 検索（AC-6）

| ID | 受け入れ条件 |
| :-- | :-- |
| AC-6-1 | メッセージ本文に含まれるキーワードで検索すると、該当するメッセージがチャンネル名・投稿者・投稿日時とともに表示され、キーワードの部分が強調される。 |
| AC-6-2 | どのメッセージにも一致しないキーワードで検索すると、一致するメッセージが無いことを示す専用の表示になる。 |
| AC-6-3 | 自分がメンバーでないプライベートチャンネルの中だけに存在するキーワードで検索すると、検索結果は0件になる。 |
| AC-6-4 | 検索結果の行を開くと、そのメッセージがあるチャンネルの画面が表示される。 |

### 7. 公開API（AC-7）

| ID | 受け入れ条件 |
| :-- | :-- |
| AC-7-1 | ログインしていない状態で `/api/channels` を開くと、公開チャンネルの名前と説明の一覧がJSONで返り、プライベートチャンネルは1件も含まれない。 |
| AC-7-2 | ログインしていない状態で、公開チャンネルの `/api/channels/{channel}/messages` を開くと、そのチャンネルのメッセージ一覧が投稿者・本文・投稿日時とともにJSONで返る。 |
| AC-7-3 | プライベートチャンネルのIDを指定して同じAPIを開くと、404が返り、チャンネル名などの情報は一切含まれない。 |
| AC-7-4 | 削除済みのメッセージがあるチャンネルで同じAPIを開くと、そのメッセージは結果に含まれない。 |

## 3. 書いていて気づいたこと

- F-30（文字数上限）とF-31（初期データ投入）は、7つの実装単位のどれにもそのまま対応しないため、単位を新設せず、関係する単位の受け入れ条件・テスト観点に織り込んだ（F-30はTC-1-2・1-4・2-2・2-3・4-2に分散、F-31はAC-1-2が初期データのアカウントを使うことで間接的に確かめる）。他の単位分けと扱いが違う点として指摘しておく。
