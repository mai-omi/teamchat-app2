# 確認事項リスト

仕様書とモックアップを読んで、自分たちで決めずに確認したい点をまとめた。
それぞれ「こちらの想定」を添えてあるので、想定で構わないものは想定どおりにする旨を、違う場合は正しい内容を教えてほしい。

各Qには、クライアントからの回答を追記している。「返ってきた回答」は原文のまま引用し、状態を **回答済み／一部回答／回答なし** で示す。「一部回答」は、聞いたことの一部にしか答えが来ていないもので、返ってきていない部分も明記する。「回答なし」のものは、まだこちらで決めずにそのままにしておく。
